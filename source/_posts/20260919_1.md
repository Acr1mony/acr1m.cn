# 光遇 PC 端双开/多开教程

如何在同一台 Windows 电脑上同时运行两个《光·遇》PC 客户端，并分别登录两个不同账号？PC端优势：画质、帧率、可选iOS或Android渠道角色。

本方案使用 Sandboxie Plus 隔离第二套启动器的单实例检测、注册表和用户数据。不修改 `Sky.exe`，不注入游戏进程，也不需要关闭游戏安全组件。实际使用时，账号 A 在普通环境中运行，账号 B 在名为 `Sky_B` 的沙箱中运行。

## 1 方案原理

把启动器复制到另一个磁盘并不能形成两套独立环境。两个 `FeverGamesInstaller.exe(启动器)` 仍会共用以下内容：

```text
HKCU\Software\FeverGames
C:\Users\<用户名>\AppData\Local\FeverGames
C:\Users\<用户名>\AppData\Local\CEF
C:\Users\<用户名>\AppData\Roaming\ThatGameCompany\com.netease.sky
```

启动器还会通过 Qt 共享内存或命名对象检测同一 Windows 会话内是否已有实例运行。第二次直接启动时，通常会提示“已经有一个实例在运行了”。

Sandboxie Plus 可以为第二个启动器提供独立视图：

| 环境 | 启动方式 | 登录账号 | 数据位置 |
| --- | --- | --- | --- |
| 普通环境 | 直接运行网易发烧游戏平台 | 账号 A | Windows 原始注册表和 AppData |
| `Sky_B` 沙箱 | 通过 Sandboxie `Start.exe` 运行 | 账号 B | Sandboxie 的虚拟注册表和文件目录 |

隐藏宿主进程后，沙箱中的启动器看不到普通环境里的同名启动器和 `Sky.exe`，从而允许两套原生 PC 客户端同时运行。

## 2 使用条件

开始前应满足以下条件：

- Windows 10 或 Windows 11 64 位系统。
- 《光·遇》PC 客户端已经安装并能正常进入游戏。
- 网易发烧游戏平台能够正常识别游戏安装位置。
- 准备两个可在 PC 端登录的账号。
- 当前 Windows 用户具有安装驱动所需的管理员权限。
- 已备份重要账号信息，并了解非官方多开的潜在风险。

建议先在任务管理器中关闭这些进程：

```text
FeverGamesInstaller.exe
FeverGamesWeb.exe
FeverGamesLauncher.exe
Sky.exe
```

## 3 下载 Sandboxie Plus

从 Sandboxie Plus 官方 GitHub Releases 页面下载 64 位版本：

<https://github.com/sandboxie-plus/Sandboxie/releases>

或我分享在蓝奏云的1.18.4版本：

<https://wwbpp.lanzout.com/i9WfS48vaa3c>

```text
Sandboxie-Plus-x64-v1.18.4.exe
```

## 4 安装 Sandboxie Plus<a id="#4"></a>

1. 运行 Sandboxie Plus 安装程序。
2. 选择 Sandboxie Plus 图形界面版本。
3. 选择安装位置。本机示例为：

   ```text
   E:\Program Files\Sandboxie-Plus
   ```

4. 同意安装 Sandboxie 系统驱动和服务。
5. 安装完成后启动 `SandMan.exe`。
6. 如果 Windows 请求管理员授权，确认发布者和安装包来源无误后再允许。

安装成功后，下面这些文件通常会存在：

```text
E:\Program Files\Sandboxie-Plus\SandMan.exe
E:\Program Files\Sandboxie-Plus\Start.exe
E:\Program Files\Sandboxie-Plus\SbieIni.exe
```

任务管理器中通常还能看到：

```text
Sandboxie Service.exe
```

如果安装在其他目录，后续命令中的 `E:\Program Files\Sandboxie-Plus` 必须替换成实际安装目录。

## 5 创建 Sky_B 沙箱 使用图形界面创建

1. 打开 `SandMan.exe`；
2. 点击左上角“沙盒”菜单；
3. 选择“新建沙盒”；
4. 沙箱名称填写 `Sky_B`；
5. 选择标准沙箱类型；
6. 完成创建。

不建议选择临时沙箱，否则关闭沙箱后可能丢失账号 B 的登录状态。隐私增强型或限制过严的沙箱也可能阻止启动器读取游戏目录。

## 6 配置沙箱外观和基础功能

在下面的列表中右键新创建的沙盒`Sky_B`，选择`沙盒选项`。

点击左侧`常规选项`-上方`沙盒选项`：

`标题栏中的沙盒标识`：建议默认`在标题内显示沙盒名称`，用来区分沙盒游戏窗口(账号B)和正常游戏窗口(账号A)；

`沙盒内窗口边框`：建议选择`为本沙盒中的所有窗口显示`，这样就能很容易的用颜色外框来区分沙盒启动器和游戏进程，点击右边默认黄色的颜色框来更改外框颜色；

点击右下角`应用`后进入宿主进程隐藏设置。

以上设置用于区分账号 B 的窗口，其他建议暂时不要修改。不同 Sandboxie 版本可能还会在窗口标题中显示 `[#]` 标记。

## 7 配置宿主进程隐藏

这是双开/多开能否成功的关键步骤。沙箱内的启动器必须看不到普通环境中的启动器和游戏进程。

依旧是右键沙盒`Sky_B`，选择`沙盒选项`。

点击左侧`高级选项`-上方`进程`-右侧`添加进程`，将以下4个进程依次添加(依次复制粘贴确定即可，一行一个)

```text
Sky.exe
FeverGamesWeb.exe
FeverGamesLauncher.exe
FeverGamesInstaller.exe
```

添加完毕后`应用/确定`即可。

## 8 可选配置沙箱数据目录

因为做一个多开沙箱的默认目录可能会占用C盘500M左右空间，如果希望把沙箱内容放在别的盘来节省系统盘空间，可以在主界面：

点击上方`选项`-`全局设置`-`高级选项`-修改`沙盒文件系统根目录`

选择一个你想要沙盒数据保存的地方点击`应用/确定`，现有的沙盒和以后创建的沙盒数据文件都会保存在所选文件夹。

## 9 启动账号 A

账号 A 使用普通环境，直接运行网易发烧游戏平台。例如：

```text
直接正常启动启动器
或你自己的游戏目录`X:\Program Files\FeverGames\1.18.43.22\FeverGamesInstaller.exe`
```

登录账号 A，并选择正确的渠道角色。不要通过 Sandboxie 启动这一份，并且必须先正常启动。

## 11 启动账号 B

第二个启动器必须由 Sandboxie 的 `Start.exe` 启动：

右键Sky_B-`运行`-`运行程序`-`浏览`-`找到启动器进程启动`

参考目录`X:\Program Files\FeverGames\1.18.43.22\FeverGamesInstaller.exe`

第二个启动器成功进入沙箱时应满足：

- 不再提示“已经有一个实例在运行了”。
- 窗口周围出现 Sandboxie 颜色边框。
- 窗口标题可能带有 `[#]` 标记。
- 任务管理器中同时存在两个 `FeverGamesInstaller.exe`。

如果没有蓝色边框，应立即关闭第二个启动器，检查是否误把启动器直接双击运行。

## 12 首次登录账号 B

新沙箱第一次运行时可能读取到普通环境的原始登录状态，因此第二个启动器可能暂时显示账号 A。这不代表隔离失败。

正确处理方法：

1. 确认正在操作带颜色边框的窗口。
2. 只在这个窗口的启动器中中退出当前账号。
3. 登录账号 B。
4. 选择账号 B 对应的渠道和角色。
5. 关闭后重新打开沙箱启动器，确认账号 B 的状态被保留。

不要在普通启动器里退出账号 A，也不要在确认窗口身份之前进行账号切换。

## 13 启动两个游戏客户端

推荐顺序：

1. 打开普通启动器并登录账号 A。
2. 打开 `Sky_B` 沙箱启动器并登录账号 B。
3. 先在账号 A 的启动器中点击“开始游戏”。
4. 等账号 A 进入登录界面或游戏世界。
5. 再在账号 B 的沙箱启动器中点击“开始游戏”。
6. 检查任务管理器中是否同时存在两个 `Sky.exe`。
7. 分别确认两个角色都能进入服务器。

如果两个游戏都能正常进入，双开配置即告完成。以后不需要重复执行创建和配置命令。

## 14 制作一键启动脚本

### 14.1 账号 A 启动脚本

新建 `Start-Sky-A.cmd`：

```bat
@echo off
start "" "F:\Program Files\FeverGames\1.18.43.22\FeverGamesInstaller.exe" -g FeverGamesLauncher -w "fevergames://mygame/?gameId=63"
```

### 14.2 账号 B 启动脚本

新建 `Start-Sky-B-Sandboxed.cmd`：

```bat
@echo off
set "SBIE=E:\Program Files\Sandboxie-Plus\Start.exe"
set "LAUNCHER=F:\FeverGames\1.18.43.22\FeverGamesInstaller.exe"

if not exist "%SBIE%" (
  echo Sandboxie not found: %SBIE%
  pause
  exit /b 1
)

if not exist "%LAUNCHER%" (
  echo FeverGames launcher not found: %LAUNCHER%
  pause
  exit /b 1
)

start "" "%SBIE%" /box:Sky_B "%LAUNCHER%" -g FeverGamesLauncher -w "fevergames://mygame/?gameId=63"
```

以后先双击账号 A 脚本，再双击账号 B 脚本即可。脚本中的路径必须与本机实际安装位置一致。

## 15 游戏和启动器更新

建议只使用普通启动器更新游戏：

1. 关闭两个 `Sky.exe`。
2. 关闭沙箱版启动器。
3. 用普通启动器完成游戏和平台更新。
4. 使用普通客户端验证更新后可以正常进入游戏。
5. 再启动沙箱版客户端。

不要让两个启动器同时更新同一个游戏目录，否则可能产生文件占用、校验失败或重复下载。

如果启动器版本目录发生变化，例如从 `1.18.43.22` 更新为新版本，需要把启动脚本中的版本目录改为新的实际路径。优先使用根目录的 `FeverGamesLauncher.exe` 或当前有效的 `FeverGamesInstaller.exe`。

## 16 日常维护

- 不要随意删除 `Sky_B`，否则账号 B 的登录状态和独立配置会被清除。
- 不要给 FeverGames、CEF 或 `com.netease.sky` 用户数据目录设置直接写入宿主机，否则两个账号可能重新共用数据。
- 游戏更新时先退出两个客户端。
- Sandboxie 更新后先测试启动器双开/多开，再登录重要账号。
- 如果需要结束账号 B 的全部进程，在 Sandboxie Plus 中右键 `Sky_B`，选择“终止所有程序”。
- 清理沙箱前确认已经记住账号 B 的登录方式，并做好重新登录准备。

## 17 常见问题排查

### 17.1 两个启动器显示同一个账号

只在带颜色边框的窗口里退出原账号 A 并登录账号 B。首次运行读取到账号 A 属于正常现象，在带颜色边框的启动器重新登录账号 B 后，修改随后会写进沙箱。

### 17.2 沙箱启动器找不到游戏

先用普通启动器确认游戏已安装且能正常运行，然后重新打开沙箱启动器。`！！！不要在沙箱中更新游戏或重新下载整套游戏！！！`

### 17.3 游戏更新后沙盒失效

检查启动器版本目录是否变化，目前为`1.18.43.22`，可能后续会发生变化，如果发生变化需要修改沙盒中路径。还应确认 Sandboxie 服务和驱动仍在运行。

### 17.4 关闭游戏后残留进程

在 Sandboxie Plus 中右键 `Sky_B`，选择“终止所有程序”。这只会结束账号 B 的沙箱进程，不会影响普通环境中的账号 A。

## 18 不建议使用的方法

为降低文件损坏和账号风险，不建议：

- 修改或破解 `Sky.exe`。
- 修改已签名的启动器二进制文件。
- 使用 DLL 注入绕过检测。
- 删除、屏蔽或关闭游戏安全组件。
- 使用来源不明的“光遇多开补丁”。
- 强制关闭未知互斥句柄后继续运行游戏。
- 让两个启动器同时更新同一个游戏目录。

## 19 卸载或恢复

如果不再需要双开/多开：

1. 关闭账号 B 的游戏和启动器。
2. 在 Sandboxie Plus 中终止 `Sky_B` 的所有程序。
3. 如需保留登录状态，先不要删除沙箱。
4. 如确认不再需要账号 B 的沙箱数据，可在 Sandboxie Plus 中删除 `Sky_B` 的内容或整个沙箱。
5. 需要完全移除时，再通过 Windows 应用管理卸载 Sandboxie Plus。

删除 `Sky_B` 会清除沙箱中的登录状态和独立设置，但不会删除普通环境中的账号 A 数据或游戏本体。执行删除前仍应仔细核对目标沙箱。

## 20 多开

依照教程创建并设置多个沙箱（例如继续添加Sky_C,Sky_D，并按照Sky_B同样设置，需要电脑配置支持多开运行）
